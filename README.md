# Bullet Journal (BuJo)

A modern Bullet Journal application built for fast capture, organization, and review of information. BuJo combines the flexibility of rapid logging with structured modules, cloud synchronization, and a responsive interface designed for desktop and mobile devices.

## Features

### Rapid Logging

Create entries using simple bullet syntax directly from the editor.

| Symbol | Type  |
| ------ | ----- |
| `.`    | Task  |
| `-`    | Note  |
| `o`    | Event |

### Signifiers

Add metadata to entries using optional signifiers.

| Symbol | Meaning  |
| ------ | -------- |
| `*`    | Priority |
| `!`    | Idea     |
| `?`    | Explore  |

### Journal Modules

* **Daily Log** — Daily tasks, notes, and events.
* **Monthly Log** — Monthly planning and review.
* **Future Log** — Long-term scheduling.
* **Collections** — Custom pages for projects, references, and topics.

### Habit Tracking

Track recurring habits through a dedicated habit management system with daily logging.

### Search

Search across all journal entries, collections, and records from a single interface.

### Insights

Visualize activity, task completion rates, and journal statistics.

### Cloud Sync

Data is securely synchronized through Firebase Authentication and Firestore.

### Responsive Design

Optimized for desktop, tablet, and mobile devices.
